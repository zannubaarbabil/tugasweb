# BookNest

BookNest adalah aplikasi toko buku online berbasis Laravel yang dibuat
sebagai project pembelajaran pengembangan aplikasi web.

## ✨ Fitur

- Autentikasi pengguna
- Pengelolaan buku
- Pengelolaan kategori
- Pengelolaan penulis
- Pengelolaan penerbit
- Keranjang belanja
- Checkout
- Pemesanan buku
- Detail pesanan
- Cetak bukti pembelian

## 🛠️ Teknologi

- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript
